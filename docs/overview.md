# 俺たちの雀歴 — アプリ概要

## プロジェクト名称

| 用途 | 名称 |
|------|------|
| 製品名（日本語） | **俺たちの雀歴** |
| 開発用英語名 | **Our Mahjong History** |

UI 上の表記（アプリ名、ページタイトル、OG タイトル等）は **俺たちの雀歴** を用いる。リポジトリ名・パッケージ名等の識別子には **Our Mahjong History**（`our-mahjong-history`）を用いる。

## 目的

麻雀仲間のグループ（**コミュニティ**）で、麻雀大会および各試合（半荘）の結果を記録・共有する Web アプリケーション。

## 想定ユーザー

- 定期的に麻雀をする仲間同士のグループ
- 大会の結果を後から振り返りたいプレイヤー
- スマートフォンから手軽に記録・閲覧したいユーザー

## アプリ種別

- **コミュニティ型**: 複数ユーザーがログインし、所属コミュニティのデータを共有
- コミュニティは卓や麻雀大会とは独立して存在（麻雀仲間の単位）

---

## ドメイン構造

```
コミュニティ（麻雀仲間の単位）
  ├── メンバーシップ（ユーザーとの N:M）
  ├── 既定ルール（複数。テンプレート。大会ルールとは別エンティティ）
  └── 麻雀大会（複数）
        ├── 大会参加者（メンバーまたはゲスト）
        │     └── 大会修正ポイント（1〜5。タイトルは大会、実額は参加者）
        ├── 大会ルール（複数。作成時に既定を値コピー。コピー元 FK なし）
        └── 試合 / 半荘（複数）
              ├── 使用ルール（大会ルールから 1 つ）
              └── 試合結果（プレイヤーごと。3 または 4）
```

- **コミュニティ**: 最上位のグループ。メンバー管理・ルール設定の単位
- **麻雀大会**: ある日開催された大会。複数の試合を含む。**複数ルールを併用できる**（四麻卓と三麻卓の混在など）
- **試合（半荘）**: 半荘 1 回分の記録。**局単位の記録は不要**。その大会のルールから 1 つを選んで使う

### 関係と多重度（Phase 1-1 / 1-2 / 1-4）

| 関係 | 多重度 | 備考 |
|------|--------|------|
| ユーザー — コミュニティ | N:M | 所属。1 ユーザーが複数コミュニティに入れる |
| コミュニティ — 麻雀大会 | 1:N | 大会は必ず 1 コミュニティに属する |
| コミュニティ — 既定ルール | 1:N | テンプレート。三麻用・四麻用など複数可 |
| 麻雀大会 — 大会参加者 | 1:N | 大会作成時は 0 人でもよい |
| 麻雀大会 — ルール | 1:N | 作成時にコミュニティ既定をコピー。大会側で追加も可 |
| 麻雀大会 — 試合 | 1:N | 試合は必ず 1 大会に属する。大会に試合 0 件も可 |
| 試合 — ルール | N:1 | その大会のルールから 1 つを選ぶ |
| 試合 — 試合結果 | 1:3 または 1:4 | その試合の使用ルールの人数（三麻 / 四麻）に従う |
| 大会参加者 — 試合結果 | 1:N | 同一大会で複数試合に出られる |
| 試合結果 — 大会参加者 | N:1 | プレイヤーは大会参加者を指す。ユーザーを直接指さない |
| 大会参加者 — 大会修正ポイント | 1:0..1 | タイトルは大会が持つ。実額は参加者あたり最大 1 行 |
| ユーザー — 大会参加者 | 1:N（任意） | メンバーのときだけ。ゲストは表示名のみ |

試合のプレイヤーは、その大会の参加者の **部分集合** である。

コミュニティ既定ルールと大会ルールは **別エンティティ**。招待と役割は 1-5。

### プレイヤーの指し方（Phase 1-1）

試合に出せるのは次の 2 種。どちらも **大会参加者** として大会に載せる。

| 種別 | 内容 |
|------|------|
| **メンバー** | そのコミュニティに所属するログインユーザー |
| **ゲスト** | アカウントなしの **表示名**。ログインできない。コミュニティ横断の名簿や名寄せはしない |

- ゲストは大会ごとの名前である。別大会の同名ゲストは同一人物として扱わない
- コミュニティに所属している人はメンバーとして参加させる。ゲストと二重登録しない
- 「プレイヤー個人の詳細管理」（プロフィール、通算成績、名寄せ）は MVP 外のまま
- データを閲覧・編集できるのはコミュニティメンバーのみ。ゲストは記録上の名前であり、利用者ではない

### 保存と計算（Phase 1-1）

| 値 | 入力 / 計算 | 保存 |
|----|-------------|------|
| 点数（持ち点） | 手入力 | 保存する |
| オカ・ウマ・トビ・焼き鳥 | 自動計算できるものは保存時に計算、できないものは手入力 | 試合結果の内訳として保存する |
| その他ポイント（1〜5） | ルールで名称を付ける。実額は試合で手入力 | 名称はルール、ポイントは試合結果 |
| 試合個別の手動ポイント（1〜3） | 試合でタイトルを付ける。実額は試合結果で手入力 | タイトルは試合、ポイントは試合結果 |
| 試合のポイント | 内訳を加味した合計（レートはルールの係数として合計に反映） | 合計を保存する |
| 試合の順位 | **点数**の高い順で保存時に計算。同点は同位で次を飛ばす（1, 2, 2, 4） | 計算結果を保存する |
| 大会修正ポイント | 手入力（チップや会場提供の優遇などを **ポイントの加減** として） | タイトルは大会（1〜5）。実額は参加者の修正行（同番号） |
| 試合ポイント合計 | その参加者の試合結果ポイントの合計 | 保存しない（都度集計） |
| 最終ポイント | 試合ポイント合計 + 大会修正ポイント | 保存しない（都度集計） |
| 最終順位 | 最終ポイント順。同ポイントは同位で次を飛ばす（1, 2, 2, 4） | 保存しない（都度集計） |

1 件でも試合が紐づいた大会ルールは **修正不可** である。内容を変えたい場合はルールを新規登録し、以降の試合でそれを選ぶ。未使用の大会ルールは修正できる。コミュニティの既定はテンプレートなので、既存大会のルールには影響しない。

保存済みのポイント（内訳と合計）・順位は、ルールを後から増やしても **変わらない**。点数を直して再保存したときは、順位を点数から再計算し、その試合が参照している（不変の）ルールで自動計算分のポイントを再計算する。

試合の順位は **点数** から付ける。オカ・ウマの上家取りは同点時のポイント配分に使い、順位は分けない。

### 大会サマリー（Phase 1-3）

正は **試合結果** と **大会修正ポイント** である。最終ポイント・最終順位は大会に保存しない。

- **試合ポイント合計** = その大会参加者の、各試合結果ポイントの合計（三麻・四麻混在やレート差も、保存済みの試合ポイントをそのまま足す）
- **大会修正ポイント** = その大会参加者の修正ポイント 1〜5 の合計。タイトルは大会が持つ（例: チップ、会場優遇）。試合のポイントとは別に持つ
- **最終ポイント** = 試合ポイント合計 + 大会修正ポイント
- **最終順位** = 最終ポイントの高い順。同ポイントは同位、次の順位は飛ばす（例: 1, 2, 2, 4）
- 順位・最終ポイントの対象は **1 試合以上出場した参加者**。未出場は参加者リストに残すが、順位対象外
- 大会修正ポイントは大会参加者に付ける（未出場者にも付けられる）。未出場者の修正は最終順位には載せない
- 修正のゼロサム制約は持たない。タイトルが空の枠は未使用（実額は 0）
- 画面上の見せ方・入力手順は Phase 2

## 用語定義

| 用語 | 意味 |
|------|------|
| **点数** | 半荘終了時の各プレイヤーの **持ち点**（素点） |
| **ポイント** | 試合結果に保存する合計。オカ・ウマ・トビ・焼き鳥・その他・試合個別手動とレートを加味した得点 |
| **試合** | 半荘 1 回分。本ドキュメントでは「試合」=「半荘」として扱う |
| **麻雀大会** | 日付・名称等を持つイベント。複数試合の容器 |
| **大会参加者** | その大会に出る人。コミュニティメンバーまたはゲスト |
| **ゲスト** | アカウントを持たない大会参加者。表示名のみ |
| **試合結果** | 1 試合における 1 参加者の点数、ポイント内訳（オカ・ウマ・トビ・焼き鳥・その他・試合個別手動）、合計ポイント、順位 |
| **ルール** | 点数からポイントを出すための設定。コミュニティの既定（テンプレート）と、大会にコピーした実体がある |
| **レート** | ルールの第一級項目。ポイント計算の係数。円など金額への換算には使わない |
| **大会修正ポイント** | 試合とは別に、大会参加者へ付けるポイントの加減。タイトル 1〜5 は大会、実額 1〜5 は参加者 |
| **最終ポイント** | 試合ポイント合計 + 大会修正ポイント。保存せず都度集計 |
| **最終順位** | 最終ポイントに基づく大会内順位。保存せず都度集計 |

## 点数計算ルール

半荘単位の入力のため、アガリ役等は扱わない。

### 置き場所（Phase 1-2）

- **コミュニティ** は既定ルール（テンプレート）を複数持てる
- **大会** 作成時にコミュニティ既定をコピーする。大会はルールを追加できる
- 1 大会で **複数ルールを併用** できる（例: 四麻卓と三麻卓の混在）
- **試合** は、その大会のルールから 1 つを選ぶ
- 1 件でも試合が紐づいた大会ルールは **修正不可**。変えたい場合はルールを新規登録する（修正の代わり）

### 第一級項目（Phase 1-2）

計算式の細部は Phase 2〜4。フィールドとして持つものだけ決める。

| 項目 | 内容 |
|------|------|
| 人数 | 三麻 / 四麻。試合結果の人数もこれに従う |
| 持ち点・返し点 | ○○点持ち ××点返し |
| オカの同着時 | **上家取り** / **折半** / **手動**。同着は **点数**（試合順位）の同着 |
| ウマの有無 | なしのとき、以下のウマ項目は使わない |
| ウマの同着時 | **上家取り** / **折半** / **手動**。同着は **点数**（試合順位）の同着 |
| ウマのポイント1 | 最上位 ⇔ 最下位 |
| ウマのポイント2 | 2位 ⇔ 3位（**四麻のみ**） |
| トビの有無 | |
| 焼き鳥の有無 | ありのとき、実際のポイントは試合で手入力 |
| その他ポイント 1〜5 | 名称のみ（例: 役満ご祝儀）。未使用は空。実額は試合結果で手入力 |
| レート | 第一級。小数、0 以上 |
| メモ | 自由記述。計算には使わない |

ポイントは、点数から自動計算できるものは自動計算し、点数から出せないもの（焼き鳥、オカ・ウマ同着時の手動、その他ポイント、試合個別の手動ポイントなど）は手入力する。内訳と合計は試合結果に保存する。

試合には、ルールとは別に **試合個別の手動ポイント 1〜3** を持てる（タイトルは試合、実額は試合結果）。

コミュニティ既定と大会ルールは **別エンティティ**（共通列 + 親 FK）。コピーは値の複製であり、コピー元 FK は持たない。

## MVP スコープ

### 含む

- 認証（ログイン / サインアップ）
- コミュニティの作成・所属
- 麻雀大会の CRUD（登録・一覧・編集・削除）
- 試合（半荘）の CRUD
- ルール設定に基づくポイント計算
- 大会サマリー（参加者・最終順位・最終ポイント。試合合計 + 大会修正）

### 含まない（将来拡張）

- 写真アップロード
- 成績・統計（勝率、順位分布等）
- プレイヤー個人の詳細管理（ゲストの名寄せ、通算成績、自己紹介等。ログインユーザーの表示名 `profiles.display_name` とゲスト表示名は MVP に含む）
- 結果のエクスポート・共有
- PC 向けレイアウトの最適化

## 権限モデル（方針）

- コミュニティメンバーのみが当該コミュニティのデータを閲覧・編集可能
- Supabase RLS（Row Level Security）で実装
- 招待制を想定（公開ルームは MVP 外）

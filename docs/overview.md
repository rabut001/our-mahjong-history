# 俺たちの雀歴 — アプリ概要

## プロジェクト名称

| 用途 | 名称 |
|------|------|
| 製品名（日本語） | **俺たちの雀歴** |
| 開発用英語名 | **Our Mahjong History** |

UI 上の表記（アプリ名、ページタイトル、OG タイトル等）は **俺たちの雀歴** を用いる。リポジトリ名・パッケージ名等の識別子には **Our Mahjong History**（`our-mahjong-history`）を用いる。

## 目的

麻雀仲間のグループ（**コミュニティ**）で、麻雀大会および各試合（半荘）の結果を記録・共有する Web アプリケーション。

## 想定ユーザー

- 定期的に麻雀をする仲間同士のグループ
- 大会の結果を後から振り返りたいプレイヤー
- スマートフォンから手軽に記録・閲覧したいユーザー

## アプリ種別

- **コミュニティ型**: 複数ユーザーがログインし、所属コミュニティのデータを共有
- コミュニティは卓や麻雀大会とは独立して存在（麻雀仲間の単位）

---

## ドメイン構造

```
コミュニティ（麻雀仲間の単位）
  └── 麻雀大会（複数）
        └── 試合 / 半荘（複数）
```

- **コミュニティ**: 最上位のグループ。メンバー管理・ルール設定の単位
- **麻雀大会**: ある日開催された大会。複数の試合を含む
- **試合（半荘）**: 半荘 1 回分の記録。**局単位の記録は不要**

---

## 用語定義

| 用語 | 意味 |
|------|------|
| **点数** | 半荘終了時の各プレイヤーの **持ち点**（素点） |
| **ポイント** | 点数にオカ・ウマ・トビ・風速等を加味した **最終的な得点** |
| **試合** | 半荘 1 回分。本ドキュメントでは「試合」=「半荘」として扱う |
| **麻雀大会** | 日付・名称等を持つイベント。複数試合の容器 |

## 点数計算ルール

半荘単位の入力のため、アガリ役等は扱わない。以下の **ルール設定** はコミュニティ（または大会）単位で保持する。

| 項目 | 例 |
|------|-----|
| 人数 | 三麻 / 四麻 |
| 持ち点・返し点 | ○○点持ち ××点返し |
| ウマ | 設定値 |
| トビ | 有無・設定 |
| 焼き鳥 | 有無・設定 |
| その他 | フリー入力 |

ポイント計算ロジックの詳細はモックフェーズ（Phase 2）および実装フェーズで具体化する。

## MVP スコープ

### 含む

- 認証（ログイン / サインアップ）
- コミュニティの作成・所属
- 麻雀大会の CRUD（登録・一覧・編集・削除）
- 試合（半荘）の CRUD
- ルール設定に基づくポイント計算
- 大会サマリー（参加者・最終順位・最終ポイント）

### 含まない（将来拡張）

- 写真アップロード
- 成績・統計（勝率、順位分布等）
- プレイヤー個人の詳細管理
- 結果のエクスポート・共有
- PC 向けレイアウトの最適化

---

## UI / UX 方針

- **言語**: 日本語のみ
- **デバイス**: スマートフォン優先。PC 表示は妥協可
- **デザイン**: Phase 2（モックフェーズ）で詳細を決定。仕様は `docs/ui-spec.md` に記録予定

---

## 権限モデル（方針）

- コミュニティメンバーのみが当該コミュニティのデータを閲覧・編集可能
- Supabase RLS（Row Level Security）で実装
- 招待制を想定（公開ルームは MVP 外）
